# فحص الأجهزة والمصادر الحية

هذه قائمة تحقق ميدانية؛ وجود الوظائف في المصدر ونجاح واجهتها لا يثبت دقة أو توفر جهاز أو خدمة حية.

| الوظيفة | الفحص المطلوب |
|---|---|
| GPS المتصفح | السماح بالموقع، تحرك فعلي، وقف التتبع، رفض الإذن وفقد الإشارة |
| JRC / منفذ تسلسلي | اختيار محول حقيقي، فحص السرعات 4800–115200 و2400، استقبال RMC/GGA/GLL/VTG/HDT/THS/HDG، فصل وإعادة ربط |
| DGPS BLE | مستقبل يدعم Nordic UART أو HM-10، التعامل مع أجزاء جمل NMEA وانقطاع BLE |
| Bluetooth COM / SPP | اقتران من النظام ثم اختيار منفذ COM؛ ليس بديلًا عن Web Bluetooth BLE |
| جهاز الأعماق | JFE-680 أو جهاز متوافق، DPT/DBT/DBS/DBK، الوحدات والـoffset والمرجع بالنسبة للمحول أو السطح أو العارضة |
| الاتجاه والمسار | مقارنة COG وHeading بالمصدر، اختبار North up وCourse up والدوران اليدوي |
| ETA/XTE | مقارنة بقيم معروفة عند الحركة وتوقف السفينة والابتعاد إلى جانبي المسار |
| المرساة | ضبط دائرة، الخروج والدخول والاعتراف بالإنذار، سماع الصوت بعد تفاعل المستخدم |
| Telegram | مفتاح بوت جديد ووجهة محددة من المالك؛ اختبار الإرسال يتم بطلب صريح، ولم يرسل فحص التجهيز أي رسالة |
| AIS | مقارنة MMSI والموقع وحداثة الهدف بمصدر معروف؛ مراقبة تعطل/تغير استجابة الموردين |
| المدّ | مقارنة تاريخ الصفحة والقمم والقيعان وأوقات بغداد بالمصدر المعتمد |
| NAVTEX | مقارنة التحذير برقم الرسالة وتاريخ النشر والحالة ومصدر NAVAREA IX |
| الطقس والبحر | مقارنة الموقع والوحدات والتوقيت، اختبار غياب البيانات البحرية وأخطاء الشبكة |
| الهاتف والأجهزة | اختبار جهاز ومتصفح فعليين؛ محاكاة حجم الشاشة لا تثبت دعم Serial أو BLE على الهاتف |

استخدم localhost أو سياق HTTPS مناسبًا لإتاحة واجهات الأجهزة بحسب المتصفح. الاختبار الآلي غطى أدوات الربط واختيار baud، دون فتح منافذ أو استدعاء أجهزة أو أذونات موقع فعلية.
